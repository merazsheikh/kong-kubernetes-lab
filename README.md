# Kong Gateway on Kubernetes Lab

Hands-on learning and portfolio project focused on Kong API Gateway and Kubernetes.

## Goals

This repository documents practical experience with:

- Kubernetes fundamentals
- Pods, Deployments, Services, and EndpointSlices
- Kubernetes networking and service discovery
- Kong Gateway
- Kong Ingress Controller
- Ingress and Gateway API
- API routing and path handling
- Kong plugins
- API key authentication
- JWT authentication
- ACL authorization
- Rate limiting
- Upstream health and load balancing
- 404, 502, and 503 troubleshooting
- Helm
- Terraform
- AWS EKS architecture
- Production operations and observability

## Environment

- Windows 11
- WSL2
- Ubuntu 24.04
- Docker Desktop
- kind
- kubectl
- Helm
- Kong Gateway

## Learning Approach

Each lab includes:

1. Architecture explanation
2. Kubernetes manifests
3. Commands used
4. Expected behaviour
5. Failure scenarios
6. Troubleshooting notes
7. Production considerations
